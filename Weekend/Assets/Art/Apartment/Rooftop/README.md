# 天台像素资源

Rooftop.png 为 RooftopArt.Build 生成的原创480×256像素场景底图，32像素对应1个世界单位，Point过滤，不压缩。透明边界外由相机显示纯黑色，没有黑色蒙版。

包含有砖缝、裂纹和排水沟的地面，带砖墙与凹门的楼梯间，金属水箱、两台有风扇与格栅的设备、晾衣线、旧椅、花盆和观测垫。四楼楼梯、五楼落点、望远镜放置位置不变。碰撞由 BuildRooftop 单独建立，不从图片像素推断。

需要重建时，先保存当前场景并停止播放，再运行 Prototype/Build fifth-floor rooftop。该工具会重建天台生成物；请将手工美术修改纳入工具或先备份。
