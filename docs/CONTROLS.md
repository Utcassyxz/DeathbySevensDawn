# 操作 · 当前版本 2026-11-01

| 按键 | 唯一用途 |
|---|---|
| WASD | 移动 |
| E | 使用当前物件；进入门、上下楼、拿取/放置/收起望远镜 |
| Enter | 推进对白、梦境、观测叙述；望远镜初始说明页开始观察 |
| R | 主动记录当前可收集的信息 |
| J | 日记 |
| B | 线索连线 |
| I | 背包 |
| F | 向鱼缸投入锡纸三角 |
| Esc | 返回或暂停 |
| 左右方向键 | 日记中切换条目 |
| ~ | 开发调试入口，首次输入 1997 |

教程顺序为邻居、冰箱新闻、沙发、书桌日记、首夜阳台观测、主动记录与确认连线。未开放的物件提示当前目标，不消耗时间。每次只由一个提示目标接收使用输入。

冰箱：E 打开，首次新闻期间维持打开；新闻看完后自动关门。重复打开不会再播放新闻。自由探索时沙发 E 休息一个时段；床 E 睡到次日。

望远镜：第一天阳台 E 使用，说明页 Enter 开始观察，之后 Enter 推进第一次观察、一小时后与复查对白，观测结束 E 收起。第二晚只提供 E 拿起望远镜，没有阳台观测选项；携带到天台观测垫 E 放置，再 E 使用。古神目击可 R 收录，获得回档必须完成第二夜泡泡会面。

楼梯：走廊西端 EXIT 门 E 进入独立楼梯间。分别靠近上行/下行梯口按 E 上下层；四楼防火门 E 回住户走廊，五楼门 E 到天台。第一层不能再下降，第五层不能再上升。其他楼层住户翼暂未开放，门锁住。

鱼缸：E 查看。持有锡纸三角并完成教程后，近身 F 投入，消耗一个。仅在人脸出现前（第一、二天）有效；第三天起晚投仍消耗，但不能逆转。普通鱼不会说话。

Enter 推进开场三脚，每按一次只踩一脚，共三次，随后自动衔接敲门与睁眼。普通夜晚不重复播放鱼梦；仅第二夜古神目击后进入泡泡梦。未觉醒者第七日结束进入末日分支。

时间显示在右上角，任务提示缩在左上角。设置中切换语言与总音量。主菜单及各按钮共用按压反馈。调试可跳过当前强制剧情，预览结局 1/2/3 并试听快版/慢版/真结局配乐；预览不增加收藏。
