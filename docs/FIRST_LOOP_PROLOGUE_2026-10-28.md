# 首轮 401 与 SKT-079 序章 · 2026-10-28

## 正常试玩顺序

1. 开始新旅程，完成原有梦境。第一天从客厅北门出公寓：401 住户贴传单，看见主角后迅速逃回屋内。
2. 回卧室睡到第二天。到客厅电视前按 E，选择看电视：新闻播报 SKT-079 超新星脉冲及电子信号波动，并交代主角的天文爱好。电视仍只消耗一个时段，早晨变午后。
3. 第二天出公寓：401 住户钉上木板封门，重进走廊后木板保留。
4. 回客厅，再通过电视度过一个时段到傍晚；到阳台望远镜按 E，看到古神。
5. E / Esc 移开视线，出现“序章 · 天穹之后”。按 E / Enter 或按钮进入序章，记录序章已进入。

## 范围与状态

- 演出使用第一版占位角色、简单位移动作、传单与木板，不制作额外房间或完整后续章节。
- 首轮为 LoopCount == 0。贴传单、封门演出、SKT-079 新闻记录和序章确认都有独立存档标记，不重复记日记，不额外发放知识。
- 古神仍沿用已有的第二天傍晚/深夜观察条件及知识去重。漏看电视不阻止观察，避免探索顺序把玩家卡住。
- 序章确认要求首轮、第二天夜间且已发现古神；进入章节不修改 Days、时段或轮回次数。
- 五条相关记录：401 传单、SKT-079 新闻、封门、古神知识、序章。既有日记未读与永久保存继续有效。
- 原有加载规则保留：退出重进从 Day 1 开始，永久知识和已见标记保留。本轮未增加完整的当轮时间/位置存档。开始新旅程会清除标记并完整重播；第二轮不会重播这段开场。

- Prototype > Test 401 first-loop prologue：临时进度完成整段回归，结束后恢复主档、备份档与临时档。

## 兼容性修正

确认序章的这一帧仍占用输入，避免同一个 E 再次打开望远镜。日记区分发现、记事、梦境；传单、新闻、封门和章节记录属于记事，旧开场梦境仍正确归类。全部首轮演出均为短暂输入锁，不移除门口碰撞或额外推进时间。
