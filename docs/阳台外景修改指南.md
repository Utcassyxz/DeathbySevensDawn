# 阳台外景：改颜色与换照片

项目中的配置位置：`Assets/Resources/BalconyViewSettings.asset`。

现在天空按早晨、下午、傍晚、深夜变色，远楼随之变亮或变暗；第1天至第7天逐渐灰暗、偏紫，夜间亮着的远处窗户逐渐减少。睡觉、推进时段、轮回、重新进入阳台都会读取当前时间刷新。

## 自己调整颜色

1. 退出 Play，在 Unity 的 Project 面板选中上述配置资源。
2. `First Day Sky` 的四个颜色依次对应第1天的早晨、下午、傍晚、深夜。
3. `Seventh Day Sky` 对应第7天的四个时段。第2至6天自动在这两组颜色之间过渡。
4. `First Day Buildings` / `Seventh Day Buildings` 是远楼颜色；`Building Brightness` 的四个值是各时段的亮度。
5. `Lit Windows` / `Dark Windows` 控制远处亮窗和暗窗颜色。

正式改参数前先退出 Play；运行时临时改配置不适合作为长期保存方式。

## 以后换照片

1. 将图片拖入 Project 面板，建议自行新建 `Assets/Art/BalconyViews` 文件夹存放。
2. 选中图片，在 Inspector 将 `Texture Type` 设为 **Sprite (2D and UI)**，`Sprite Mode` 设为 **Single**，点击 **Apply**。
3. 选择 `Assets/Resources/BalconyViewSettings.asset`，展开 `Day Photos`，保持数组大小为7。
4. 将照片依次拖入：Element 0是第1天，Element 1是第2天，直到Element 6是第7天。
5. 留空的天数自动使用原有远楼及变色占位。填入照片的当天会隐藏远楼和远处窗灯，显示照片。
6. 默认保持照片自身颜色；若希望照片随时段和天数一起染色，勾选 `Tint Photos With Time`。
7. 默认照片保持比例、完整放入原远楼区域。`Photo Offset` 调整构图位置，`Photo Area Scale` 调整大小。放大或移动后请检查是否遮住栏杆或地板。

照片资源及其 `.meta` 文件需要一起保留。这里配置的是阳台外景，与卧室窗外那套七日图片分开。

## 代码里的中文注释

- `Assets/Scripts/Interaction/BalconyViewSettings.cs`：搜索 **【改颜色看这里】**、**【以后换照片看这里】**。
- `Assets/Scripts/Interaction/BalconyTimeView.cs`：搜索 **【配置入口】**。该脚本负责响应时间并显示颜色/照片；通常不需要修改。
- 外景自动绑定名为 `Balcony` 的场景，以及名为 `Distant building...`、`Distant window` 的远景对象。以后重命名这些场景/对象时，需要同步调整脚本中的名字。

## 验收

进入阳台，按 `~` 后输入 `1997`，用“推进时段”依次查看四色；推进到不同天数比较远楼与天空。离开再返回，颜色应与当前日期一致。轮回后应恢复第1天早晨配色。
