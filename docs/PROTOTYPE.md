# Prototype 0.1 — The First Loop

## Target experience

The player wakes in a small apartment on Day 1, talks to an NPC, investigates one strange object, gains a persistent Knowledge flag, reaches a forced death, enters a temporary Void scene, and wakes again on Day 1 with a new dialogue option.

## Required scenes

- `Apartment`
- `Void`
- `Boss_Test` (placeholder only for Milestone 0.2)

## Required knowledge entry

`apartment_radio_signal`

Example payoff after the first loop:

> [Knowledge] "The broadcast begins before the emergency alert."

## Definition of done

The player can prove that knowledge survives death without using the Inspector or debug console.
