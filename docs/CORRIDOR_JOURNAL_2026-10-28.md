# 走廊门牌与日记阅读优化 · 2026-10-28

## 走廊

北墙左门 401、右门 403；玩家公寓为南侧 402。402 门牌落在门槛前，避免出生点角色遮住号码；仍使用低矮的南墙剖面。数字为共享材质的像素图形，不依赖系统字体，不增加碰撞体。邻门补门边与门槛细节，玩家入口保持畅通。

编辑器菜单：Prototype > Set corridor rooms 401 402 403。生成器可重复执行，房间连接不变。

## 日记

保留现有 StoryJournal 数据、知识奖励、输入锁与已读保存。左边为独立滚动的目录，右边为独立滚动的正文和插图；纸页、书脊、选中条目和未读标记具有清楚的层次。分类为全部、发现、梦境。新记录在前，支持点击、上一则/下一则和左右方向键。J / Esc 或右上“合上”返回场景。

## 设计参考与技能

参考 Mobius Digital 对《Outer Wilds》的日志标记对比度、文字适配和完整滚动的改进，采用清楚的未读状态、可完整滚动的内容及独立目录。双栏纸页布局为本项目制作，未复制其他游戏素材或故事。

参考：https://www.mobiusdigitalgames.com/news/archives/12-2019

按用户授权安装 Unity-Technologies/skills 的 ui 与 ui-ugui。来源：https://github.com/Unity-Technologies/skills/tree/main/skills 。技能安装在本机 Codex 技能目录，下次对话自动加载，不构成 Unity 工程依赖。遵循先检查项目现有结构的原则，本轮保留原日记渲染与存档体系。

## 验证

Unity 6000.6.7f1 正常 DX11 窗口中执行扩展的 Feedback interaction acceptance：日记左右翻阅、窗户 E/Esc、未读持久化、第二夜望远镜、返回后的移动、Days 跨房间保留及三块门牌位置。另检查 8 条步行通路可达。实际查看走廊和日记截图，402 不被出生点玩家覆盖，正文与插图不盖住页脚。测试使用临时进度，结束恢复原存档。
