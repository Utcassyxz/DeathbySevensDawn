# 主角日记、开场梦境与望远镜

已直接接入 `C:\Users\hongy\source\DeathbySevensDawn\Weekend`。已有场景文件未改写，望远镜运行时自动放到阳台。

## 怎么玩

- 首次进入本次旅程时，展示四幕中文梦境：童年与父母争吵、看到蚁穴、愤怒地踹塌蚁穴、惊醒。点击“继续”翻幕，最后点击“惊醒”，进入卧室。当前为可运行的文字叙事版本，没有制作角色动画或配音。
- 梦境完成后保存标记和“梦里的蚁穴”日记。普通轮回和重新启动不会重复播放；结局后确认重新开始旅程会清除旧进度并重新播放。
- 按 **J** 翻开/合上日记，或按 **Esc** 关闭。日记使用纸色底、第一人称正文，显示发现当天与旅程次数。获得知识时自动写入日记。
- 第二天白天查看卧室窗外，仍按原规则获得普通知识，并写入日记。
- 阳台右侧、南栏杆附近新增望远镜。靠近后按 **E**。
- 只有 **傍晚、深夜**可以观察；早晨、下午互动只提示等待天黑，不显示异常，也不奖励知识。
- **第二天傍晚或深夜**观察，会展示古神轮廓图，获得高级知识“天穹后的轮廓”，同时将文字和图片记入日记。
- 其他夜晚只显示普通观测文字，不发放该知识。观察不额外推进时段。
- 高级知识暂对应现有 **宇宙知识**：默认知识 +30、变异 +20、额外理智负担 +12，另外仍计算全局知识/变异带来的理智下降。
- 同一知识 ID 只发放一次，日记也只记录一次；跨轮回、退出后重进仍保留。
- 测试面板仍默认隐藏，按 **~ → 1997** 解锁一次，之后本次游戏中直接按 ~ 开关。

## 快速验收

1. Play，点击梦境的“继续”直到“惊醒”，确认出现在卧室。
2. 按 J，查看“梦里的蚁穴”。再次按 J 关闭。
3. 靠近床，按 E，睡到第二天。查看窗外，确认普通知识进入日记。
4. 使用调试面板推进两个时段到第二天傍晚，关闭面板，前往阳台右侧的望远镜。
5. 按 E，确认显示古神图和获得高级知识提示。关闭后按 J，选择“天穹后的轮廓”，确认文字、类别和图片。
6. 重复观察，确认不再增加知识，也不增加重复日记；轮回后再次按 J，确认记录仍在。
7. 早晨、下午测试望远镜应显示不能观察的提示；第一天、第三天夜间不应获得古神知识。

## 后续自己修改

主要选中 `Assets/Resources/StoryContent.asset`，在 Inspector 修改：

| 配置 | 用途 |
|---|---|
| Dream Pages | 开场每一幕的文字，数组中一项对应一幕 |
| Discovery Text | 观察古神后的文字，同时作为日记正文 |
| Ancient God Tier | 高级知识使用的现有属性档位，默认 Cosmic |
| Ancient God Image Resource | 图片的 Resources 相对路径，不含扩展名 |
| Telescope Position | 阳台望远镜位置，默认 `(2.3, -1.15)` |
| Telescope Range | 玩家离望远镜多近可互动，默认 1.2 |

**替换古神图**：替换 `Assets/Resources/Story/AncientGodDay2.png`，保留同名 `.meta`。图片使用普通 Texture 导入即可；代码保持比例显示。保留资源路径能让已保存的日记继续找到新图。

**添加知识内容**：创建 `Knowledge Data` 资源，填写唯一 ID、标题、Description、Tier；有插图时填 Journal Image Resource。调用原有 `KnowledgeManager.Unlock(knowledgeData)` 会一起获得属性和日记。正式内容应填写完整标题正文，不要只使用测试用随机 ID。

旧版本的存档会自动为已有知识补上日记，不重新发放属性；未记录标题的旧知识使用通用描述。未知类别的旧字符串知识只能按普通类别展示，因为旧档未保存类别。已有日记正文保存在存档里，修改配置主要影响后续新获得的记录。
