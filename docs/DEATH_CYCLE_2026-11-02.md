# 死亡轮回、第五天爆楼与第四天的小鱼 · 2026-11-02

本修订覆盖早先的“满七天自动回档”和“小鱼永久保留人形”规则。唯一 Unity 工程仍是 Weekend。

## 场景和空间

所有八个可运行场景及其 .meta 统一在 `Weekend/Assets/Apartment/`：SampleScene、Bedroom、LivingRoom、Bathroom、Balcony、Corridor、Stairwell、Rooftop。不另建工程；场景 GUID 未变，房间门的路径、Build Settings、维护和验收脚本同步更新。以后新增运行场景也放这个目录。

客厅书架对象、渲染、碰撞及原父对象引用一并移除；走廊 Player 的整体尺寸缩到原来的 70%，碰撞一起缩小。EXIT 移到走廊右侧墙面并改为窄侧视门面；交互点与返回落点同步移动。401/403 和下侧 402 不变。楼梯间仍由下侧独立防火门进入。

## 时钟、睡眠和死亡

- Days 是唯一日期；不再以第七天作为时钟上限。未死亡、两项危机都已解除时可活到第八天及以后。
- 原地等候和沙发推进时段不再强制调用睡眠，也不把人送到床边。实际选择床上睡眠仍走 NightDreamSequence，并在卧室床边醒来。
- 每次不睡跨过午夜计一个缺觉日。前两个不扣理智；第三个起每个缺觉午夜扣 5 SAN。实际睡眠清零缺觉天数。没有新增自动现实计时器。
- LoopManager 只订阅 GameManager.Died；健康状态不能直接调用 RestartLoop 回档。泡泡的恩赐依然需完成首次会面；未获得恩赐的死亡进入终局，没有凭空得到轮回。
- 第五天深夜越过午夜／试图睡过该节点时，若未解除爆楼危机：先播放大楼爆炸、坍塌和灰尘的像素演出。已获恩赐者首次致死事件保留泡泡重逢与恩赐说明，读完才正式死亡并回档。后续仍未解决则再次死亡，不重播首次说明。
- 第七天保留一个独立、未解除就致死的危机检查点。具体解除剧情尚未编写；不假装已有可通关路线。当前正式流程第五天未解除爆楼时会先死亡，抵达不了第七天。
- 邪教徒认为杀尽生命即可避免异化，负责净化自己分配到的整栋楼；第四天起敲门能听见他核对区域和“清掉活物”的话。第一层大门第二天起提供内侧钉死的检查描述。
- 没有把危机解除方式擅自写成拆弹谜题。调试面板提供独立测试开关，以验证继续生存的框架；正式解决途径待用户补写。

## 小鱼

锡纸仍只在第三天长脸前有效。第三天开始说话并提前提供第一个理解选择；第三夜一晚长成人形，第四天早上叫醒雨果，随后推缸、搬凳并坐在原缸位置。不要求先获得永久关系。

第二个理解话题前移至第四天；调查证词和随机闲聊仍需主动互动／收集。人形用现有小像素女性模型，对话才展示细致立绘，不再发展为雨果替身。旧第七夜替身杀人睡眠分支已退出正式流程。

死亡重置她的身体、理解、关系、凳子和锡纸保护；泡泡的全局解锁、恩赐及已主动收集知识仍保留。v5 存档兼容 v1–v4，迁移清掉旧永久人形和借凳标志；每次死亡也清理本轮物品。

若没有在床上睡着，小鱼在雨果原位置叫他，不为晨间演出强制传送卧室；随后去客厅搬家具仍是明确的剧情转场。

## 调试

键位维持：Enter 剧情；E 使用；R 记录；J 日记；B 连线；I 背包；Esc 返回；F 仅投锡纸。`~` 打开面板，1997 解锁本次会话。

解锁后进入自由调试：跳过当前强制演出、解除教程交互限制、暂停致死危机和自动晨间／泡泡梦。关闭面板后自由模式继续，面板内可显式关闭。不会把自由调试开关写入存档；重新运行默认为正常模式。

新增日期／时段选择、七个游戏场景直达、原地等到次日、第五天／第七天危机已解除测试开关、大楼爆炸预览。预览不伤害、不授予恩赐、不记录结局，也不留下可在下次运行继续执行的致死检查点。实际死亡测试走 Damage，禁止活着强行轮回。

## 音画和代码边界

WorldEndSequence 是唯一危机演出／泡泡重逢所有者；TimeManager 只请求演出，正式死亡仍交 GameManager。首次说明与 pending 检查点分别保存，避免演出抢先回档。

BuildingBlast.wav 为本项目原创合成：低频冲击、碎裂及逐渐衰减的坍塌尾声，3.6 秒，峰值约 -2.4 dBFS，播放增益再降低约 6 dB，接现有 ApartmentMix 和主音量。沿用已有死亡尖叫与泡泡配乐承接，未替换用户喜欢的旋律。生成源为 Weekend/Tools/generate_building_blast.py；没有下载外部配乐或未经授权素材。
