## 5. 下一步目标 B：重写台词，降低 AI 味

### 现状

- 所有剧情/对白/线索正文已在 `StoryText.json`。
- 但当前大部分文本仍是旧的解释型/总结型写法，确实有 AI 腔。
- 不能直接润色，否则双语时还要再翻一遍。

### 建议顺序

先做双语数据结构，再一次性重写中英文本。

### 文风规则（建议写进项目文档）

- 少解释，多具体动作和感官细节。
- 少用「不是……而是……」「仿佛/像是」连续堆叠。
- 少用抽象大词：命运、真相、存在、救赎、深渊。
- 让角色说短句，允许停顿和答非所问。
- 主角：克制、观察型，不总结主题。
- 401 邻居：破碎、警惕、句子不完整。
- 001：平静、事实陈述式，越平静越不正常。
- 线索正文保持可推理的事实边界，不能为了氛围写得含糊到无法判断。
- 梦境可以更断裂，但每页只保留一个核心意象。

### 文件

- 所有叙事/对白：`Weekend/Assets/Resources/StoryText.json`
- 线索/推论正文：同一文件的 `investigation`
- 不要改回 MonoBehaviour 硬编码。

### 验收

- 同一段文字不再出现明显的“总结句 + 升华句”结构。
- 线索板上的文本仍然能支持推理。
- 中英双语语气一致，不是机翻。

### 当前阻碍

`StoryText.json` 目前是单一中文结构，`StoryText.Current` 只返回一份数据。

### 推荐架构

方案 A（推荐，仍符合“一个文案文件”的规则）：

```json
{
  "zh": { "dream": {...}, "knowledge": {...}, ... },
  "en": { "dream": {...}, "knowledge": {...}, ... }
}
```

- `StoryTextData` 保持不变。
- 新增 `StoryTextBundle { StoryTextData zh; StoryTextData en; }`。
- `StoryText.Current` 根据 `Language` 返回 `zh` 或 `en`。
- `StoryText.Language` 持久化到 `PlayerPrefs`，默认中文。
- 主菜单和暂停菜单增加「中文 / English」切换。
- 切换后立即刷新 UI；如果对话进行中，关闭或重载当前文本。

方案 B：

- `StoryText.zh.json` / `StoryText.en.json` 两个文件。
- 加载器按语言选文件。
- 更简单，但不再是一个文件。

### 需要一并处理的 UI 文案

- 线索板筛选/按钮/空状态。

## 7. 下一步目标 D：主菜单质感 + 开场异化动画

### 当前状态

`MainMenuUI.cs` 目前是静态 IMGUI：

- 渐变背景。
- 星点。
- 标题/副标题/tagline。
- 开始/退出按钮。

它只是功能可用，不是最终主菜单。

### 目标画面

**待机主菜单：**

- 深空背景。
- 地球很小，偏下方或画面中央偏下。
- 星场、微弱星云、扫描线/噪点。
- 标题与按钮悬浮在深空上，不要遮住地球。
- 像素风格：低分辨率画布 + 最近邻放大，避免平滑渐变。

**点开始游戏后：**

1. 地球保持在画面中，镜头缓慢推近/地球轻微放大。
2. 触手从海洋/云层下钻出，缠绕地球。
3. 火焰、烟、灰烬从裂缝喷出。
4. 地球颜色异化：蓝绿 → 病态绿/紫黑。
5. 屏幕抖动、扫描线、像素错位、短促黑屏。
6. 淡出，进入开场梦境或 Bedroom。

**氛围关键词：**

- 深空、渺小、冷、静。
- 异化、触手、火焰、烟、克苏鲁。
- 像素、低饱和、脏色、抖动。
- 不要让地球变成“特效大片”，要保留“远处的、无声的、不可逆的”感觉。

### 技术建议

- 保持主菜单是持久全屏 UI，不必新建场景。
- 新增 `OpeningSequence` 状态机，避免继续把 `MainMenuUI` 写成巨类。
- 用低分辨率 `RenderTexture`（例如 480×270 或 320×180）绘制像素画面，再点采样放大到屏幕。
- 占位阶段可以程序化生成地球/触手/火焰/烟；正式阶段替换 sprite sheet。
- 动画结束回调 `StartNewJourney()`；在动画期间阻塞输入和重复点击。
- 主菜单 idle 状态可以播放缓慢星场/地球自转，增强质感。
- 像素字体：英文用像素字体；中文需要可读的中文字体或位图字库，注意不要混用成“像素背景 + 平滑中文”。

### 交付拆分

1. 主菜单 idle 重做：深空、地球、星场、按钮层级。
2. 开场异化序列：触手、火、烟、抖动、淡出。
3. 接入 `StartNewJourney`。
4. 最终美术替换与像素字体。

### 验收

- 主菜单第一眼能看到“深空里的地球很小”。
- 点开始后有完整异化动画，不是直接黑屏/直接加载。
- 动画像素风统一，没有平滑渐变混入。
- 动画结束进入梦境，输入锁正常。
- 跳过/重复点击不会触发两次新游戏。
