# 1. 设计目标

## 1.1 体验目标

第一阶段要完成三件事：

1. **第一天让人觉得“不对劲”**
2. **第二天让人觉得“逃不掉”**
3. **第七天让玩家面对一个无法绕开的死亡危机**

核心情绪：

> **Hugo 宁愿被替代，也不愿开口求人留下来。**

恐怖来源不是怪物跳脸，而是：

- 邻居在变成怪物之前，仍然像个人；
- 鱼在替 Hugo 难过的同时，想取代他；
- 泡泡很可爱，但它不理解人类；
- 时间自己在走，玩家没有“站在原地想清楚”的安全区。

## 1.2 核心设计原则

1. **时间自动流动**
   - 不是只有睡觉才能推进剧情。
   - 对话、阅读、线索板、暂停、过场时暂停时间。
   - 玩家不睡觉，时间也会走到下一天。
   - 关键事件有“追上门”机制，不能因为玩家迷路而永久错过。

2. **密集刺激**
   - Day1/Day2 每个时段都有新事件。
   - 主事件间隔不超过 90 秒空白。
   - 环境事件每 20–40 秒一次：锤声、电话、电视雪花、水管、脚步、广播、灯光。
   - 不靠“任务列表”推动，而靠时间、声音、人物、环境。

3. **Hugo 是 ENTP**
   - 先观察、追问、拆逻辑、找漏洞。
   - 嘴比脑子快，容易在危险里继续问。
   - 用玩笑和打岔回避亲密。
   - 语言失效后才真正慌。
   - 不是全知侦探，不是战斗专家，不是吐槽机器。

4. **线索板是玩家的思考工具，不是任务清单**
   - 保留推理连线。
   - 不新增“任务目标 / 未完成清单 / 下一步按钮”。
   - 提示用 Hugo 的口吻，用 NPC、环境、日记给。
   - 连线失败要区分“没关系 / 缺证据 / 日期没到 / 前置没发生”。

5. **3D 是认知滤网撕裂，不是主要探索方式**
   - 短暂、强烈、可读。
   - Day2 深夜邻居戏是 3D 的重点。
   - Day7 最终危机可以混合 2D/3D，但优先级是压迫和可玩性。

# 2. 世界观 Canon

## 2.1 辐射与异化

古神经过地球时带来辐射。

辐射不会直接把人类变成怪物，而是：

> **让欲望具象化。**

人最终会变成自己内心最深处想要的样子：

- 想被照顾的人，会变成依赖他人的东西；
- 想被需要的人，会变成替别人活的东西；
- 想保持纯净的人，会变成清除一切生命的东西。

异化不是瞬间的，而是从细节开始：

- 眼睛先抽搐；
- 语言开始断裂；
- 身体做出与本人意愿相反的动作；
- 最后，外表变成欲望的形状。

## 2.2 三角教的净化逻辑

三角教认为：

- 生命是容器；
- 欲望会从裂缝里长出来；
- 所有活物最终都会异化；
- 唯一的彻底净化，是在异化完成前清除这片区域的所有生命。

他们的话术不是“屠杀”，而是：

> **清干净。空容器不会长出东西。**

这让他们可怕，但也让他们自洽。

## 2.3 邻居的分配区域

邻居是三角教分配到这片区域的执行者。

- 他负责这栋楼，或者以 401 为中心的管辖区。
- 他手里有分配令。
- 他相信自己在救人：
  - “你们再活下去，会变成更糟的东西。”
  - “我得在你们变成那样之前，把你们清干净。”
- 他自己也在异化。
  - Day2 深夜，眼睛先开始抽搐。
  - 他知道自己快不是自己了。
  - 所以他要在第七天之前完成净化。

这让他不是纯反派，而是一个**已经被恐惧和信仰吃掉的普通人**。

## 2.4 为什么是第七天

第七天是古神影响最强、异化最接近不可逆的节点。

- 第三天：邻居开始安装/测试净化装置，不是正式死亡点。
- 第四至六天：邻居身体恶化，城市异化加重。
- 第七天：他必须在午夜前清完整栋楼，否则整栋楼会变成他无法控制的东西。
- 第七天午夜：如果玩家不阻止，楼被爆破，Hugo 死亡。
- 如果玩家有泡泡的轮回能力：
  - 死亡后回到 **第七天早晨**；
  - 保留记忆和装置知识；
  - 继续尝试。
- 如果没有轮回能力：
  - 正式结局，不再重复。

**第一阶段唯一的必死危机就是第七天的净化爆破。**

当前第三天的爆楼必须降级：
- 第三天只能出现“装置前兆/安装/测试”；
- 不得作为正式死亡点；
- 第五天城市搜捕作为压力或支线，不能和第七天抢“唯一必死”的位置。

# 3. 角色圣经

## 3.1 Hugo — ENTP

### 核心欲望

- 想被看见，又怕被看见“没用”。
- 想有人听他说话，但不肯承认自己需要人。
- 用推理、玩笑、转移话题来避免直接表达脆弱。

### 行为特征

- **Ne**：一秒联想到很多可能，容易追问，容易打岔。
- **Ti**：拆逻辑，找矛盾，喜欢在脑内建模。
- **Fe**：能读空气，但不愿承认自己在乎，常用玩笑缓和气氛。
- **Si**：生活失序，旧望远镜、旧衬衫、反复热饭是他的安全区。

### 恐怖场景中的反应

1. 先观察；
2. 追问；
3. 试图讲道理；
4. 发现语言失效；
5. 才真正慌。

### 禁止写法

- 全知侦探；
- 战斗专家；
- 每句话都吐槽的机灵鬼；
- 对邻居的悲剧毫无反应；
- 永远正确。

## 3.2 邻居

- 不是“邪教疯子”，是一个被分配了任务的普通人。
- 相信屠杀是净化，是救人。
- 知道自己也在异化，但想先把事情做完。
- 对 Hugo 有真实的、粗糙的关心：
  - 问他吃没吃；
  - 让他别回来；
  - 但身体会挡门。
- 他的台词短、停顿多，像很久没跟人说话。

## 3.3 小鱼

- 她听见了 Hugo 所有的抱怨。
- 她把“让他好受一点”误解成“替他活”。
- 她说话具体、生活化，不总结情绪。
- 她不是导师，是一个用错误方式爱人的东西。
- 不封缸：Day3 人脸、Day4 说话、Day5 肢体、Day6 模仿、Day7 替身/同伴。
- 封缸：鱼线关闭。

## 3.4 泡泡

- 可爱、礼貌、慢、轻。
- 对 Hugo 有兴趣，但不完全理解人类。
- 用日常比喻，不用宇宙术语。
- 不解释全部真相。
- 550W 式语气，但更温柔、更不对劲。
- 关键台词：
  - “你好，人类。你可以叫我泡泡。”
  - “你看起来像一张被雨淋过的纸。”
  - “等一切终焉的那一天，你我会再见面。”

# 4. 第一阶段七日结构

## Day1：一个不想出门的人

目标：让玩家感到“今天不对劲”，但还不知道是什么。

| 时段 | 事件 |
|---|---|
| Morning | 醒来、锤声、手机未接来电、前同事约饭、房东催租、母亲来电 |
| Morning | 出门遇邻居：问“今天没出门？”“电视开着吗？”“昨晚看星星了吗？” |
| Morning | 邻居手抖、门口两瓶水、收音机老歌、钉门、警告 |
| Afternoon | 冰箱、电视四条新闻、Hugo 对新闻的生活化反应 |
| Afternoon | 鱼缸喂食，Hugo 对鱼说“今天也没去面试” |
| Afternoon | 锤声停、水管响、手机亮、电视雪花 |
| Evening | 望远镜、Hugo 以前讲星空的记忆 |
| Night | 第一次观测；自动一小时；复查；遮挡扩大 |
| Night | 回家时 401 灯亮、锤声节奏变化 |

**关键体验：**

- 玩家知道邻居在隐瞒；
- 玩家知道星空在变化；
- 玩家感觉到 Hugo 在躲什么；
- 但还没有真正被追。

## Day2：邻居像个人，然后不再是

目标：先建立人性，再摧毁它。

| 时段 | 事件 |
|---|---|
| Morning | 城市日常：夜班店员、喂猫老人、值班人 |
| Morning | 靠近 401 偷听：“第三夜、整栋楼、不会留下人” |
| Morning | 敲门、进入 401 |
| Afternoon | 邻居问“你吃了吗”；两只杯子；锤子放远 |
| Afternoon | 和平/威胁/追问/提分配令；获得锡纸、维修线索 |
| Afternoon | 鱼缸、城市、广播 |
| Evening | 邻居来电/敲门：“你过来一下。我好像……不太对。” |
| **Late Night** | **Day2 深夜邻居抽搐/追逐戏（核心）** |
| Night | 回到公寓，Bubble 梦/轮回能力 |

## Day3：净化装置的前兆

- 不是正式死亡点。
- 邻居在 401/地下检修间安装净化装置。
- 玩家发现分配令、燃气/电路改造、定时器。
- 鱼：Day3 人脸。
- 玩家可以破坏一次测试，但邻居还有备用装置。
- 玩家意识到第七天会有更大的事。

## Day4：鱼说话

- 鱼 Day4 开始说话。
- 玩家选择理解/误解。
- 城市搜捕/异化加剧。
- 邻居身体开始明显异常。

## Day5：城市压力

- 城市搜捕、封锁、广播。
- 不是第一阶段必死危机；可以是支线/压力/失败可挽回。
- 玩家获得第七天装置的关键证据。

## Day6：真相接近

- 邻居失联。
- 城市广播点名 Hugo 的地址。
- 装置进入最后阶段。
- 鱼/泡泡/邻居关系收束。

## Day7：净化

- 第一阶段唯一必死危机。
- 白天：异常安静、煤气味、纸条。
- 下午：确认装置、分配令、引爆方式。
- 傍晚：楼被封锁、住户敲门。
- 夜晚：最终对峙；23:00 后进入倒计时；23:30/午夜爆炸。
- 失败：Day7 短循环，或正式结局。
- 成功：楼保住，第一阶段结束。

# 5. Day2 深夜邻居戏：完整设计

## 5.1 触发

- Day2 Night 23:10 左右自动触发。
- 401 灯亮着，锤声停止。
- 邻居打电话/敲门：
  - “你过来一下。”
  - “我好像……不太对。”
- 玩家不能轻易错过；如果玩家不在家，用手机/邻居敲门/广播追上门。

## 5.2 2D 阶段

1. 走廊：401 门虚掩，门缝有电视雪花光。
2. 进门：灯暗，电视雪花，桌上有两只杯子，一只倒扣。
3. 邻居背对玩家坐着，收音机放老歌。
4. 他问：“你来了。门关上了吗？”
5. 对话选项：
   - 追问：“你眼睛怎么了？”
   - 安抚：“你先坐下。”
   - 拆逻辑：“你刚才说‘清干净’。清什么？”
   - 观察。
6. 右眼第一次抽搐。
7. 他笑：“没事，最近有点累。”
8. 第二次抽搐，半边脸跟着动。
9. 玩家选择：追问 / 后退 / 观察 / 安抚。
10. 抽搐扩散到脖子、肩膀。
11. 他站起，椅子倒地，灯闪。
12. 他说：
    - “别看我。”
    - “我不想这样。”
    - “走。”
13. 身体挡在门口。
14. 画面沿家具位置撕裂，进入 3D。

## 5.3 3D 阶段

- 第一人称，低照度，可读性优先。
- 邻居移动是抽搐式的：
  - 停顿；
  - 抽搐；
  - 突然逼近；
  - 眼睛一直看着玩家。
- 玩家目标：逃到门口，不是杀死他。
- 可打、可躲、可试图说话；说话只能争取时间。
- 控制提示只出现一次：
  - 左键挥击；
  - Shift 冲刺；
  - Ctrl 蹲下；
  - Q 闪避；
  - E 出口/互动；
  - Esc 暂停。

## 5.4 结果

- 逃脱：
  - 门在身后合上；
  - 理智下降；
  - 获得线索：“他的眼睛先动，身体才动。”
  - 邻居没有追出来。
- 第一次被抓：
  - 黑屏；
  - 在走廊/公寓醒来；
  - 理智损失；
  - 邻居门锁死；
  - 不直接死亡，避免第一次就打断节奏。
- 第二次被抓：
  - 死亡；
  - 有轮回能力 → Day2 早晨；
  - 没有 → 正式结局。

## 5.5 声音设计

- 锤声停止后的安静；
- 收音机老歌；
- 眼球抽搐的细响；
- 椅子刮地；
- 灯管电流；
- 邻居呼吸；
- 追逐时的心跳；
- 门合上。

不要用廉价的全屏 jumpscare。  
恐怖来自“你看着他一点点不再是那个人”。

# 6. Day7 净化危机：完整设计

## 6.1 教会逻辑

邻居相信：

- 生命会异化；
- 空容器不会；
- 所以要在第七天午夜前清完整栋楼；
- 方式是引爆 401 支路/地下检修间的装置。

他不是“想炸楼”，他是“在净化”。

## 6.2 第七天结构

### Morning

- 城市广播：居民留在室内。
- 401 没有锤声。
- 走廊有煤气味。
- 门缝纸条：“今晚别回来。”字迹很抖。
- 玩家可以调查 401 / 检修间 / 城市 / 鱼 / 泡泡。

### Afternoon

- 确认装置、引爆方式、分配令。
- 邻居的遗书/生活痕迹。
- 广播开始点名 Hugo 的地址。

### Evening

- 楼门被封。
- 住户敲门。
- 401 电视雪花，鱼缸震动。
- 玩家选择：
  - 拆装置；
  - 救人；
  - 找邻居对质。

### Night

- 23:00 最终对峙。
- 邻居身体部分异化，语言断裂，但仍有人性残片。
- 玩家可以：
  1. 拆装置（需要之前的证据/推理）；
  2. 说服邻居（用他的逻辑反问他）；
  3. 逃生/救人。

### 失败

- 23:30/午夜爆炸。
- 有轮回能力 → Day7 早晨重来，保留装置知识。
- 没有 → 正式死亡结局。

### 成功

- 拆除装置/说服/保住大楼。
- 邻居可以死、被制服、或自己走进爆炸。
- 第一阶段结束。

## 6.3 邻居的 Day7 台词

```text
邻居：你来了。
Hugo：楼里都是煤气味。
邻居：嗯。
Hugo：你打算把楼炸了？
邻居：不是炸。是清干净。

Hugo：清干净以后呢？
邻居：就不会变了。
Hugo：你也在楼里。
邻居：我先清我自己。

Hugo：分配令上写的是“清除活物”。
Hugo：不是净化，不是拯救。
邻居：……那是他们的说法。
Hugo：你连自己写的东西都不敢看？

邻居：还有七分钟。
Hugo：七分钟后呢？
邻居：这栋楼就干净了。
Hugo：然后你呢？
邻居：我也干净了。
```

# 7. 自动时间系统规格

## 7.1 时间结构

- Morning：07:00–12:00
- Afternoon：12:00–17:00
- Evening：17:00–21:00
- Night：21:00–02:00
- 每个时段约 5–7 分钟真实时间。
- 一天约 20–25 分钟。
- Day1/Day2 是重点，Day3–6 可短，Day7 加长。

## 7.2 暂停规则

时间暂停：

- 对话；
- 叙事卡；
- 日记；
- 线索板；
- 背包；
- 暂停菜单；
- 3D 过场；
- 场景加载；
- Boss/处刑演出。

时间继续：

- 自由移动；
- 阅读环境；
- 发呆；
- 等待。

## 7.3 时间消耗

- 调查物件：+5–10 游戏分钟。
- 跨房间/楼层：+10–20 游戏分钟。
- 原地等待：时间自然流逝。
- 睡觉：跳到次日 07:00。
- 不睡到 02:00：自动进入次日 Morning，`sleeplessDays++`，理智代价。

## 7.4 事件导演

新增 `ApartmentEventDirector`：

- 按 Day + Period + minute 触发主事件。
- 环境事件每 20–40 秒一次。
- 主事件间隔不超过 90 秒空白。
- 关键事件有追上门兜底：
  - Day2 深夜没去 401 → 邻居打电话/敲门；

# 8. 推理连线与引导

## 8.1 内部推理链

这是给策划/QA 看的，不直接展示给玩家。

| A | B | 结论 |
|---|---|---|
| 缺了一块的星空 | 一小时后的复查 | 遮挡在扩大 |
| 邻居的警告 | 新闻摘录 | 他知道什么 |
| 邻居的警告 | 401 的木板 | 封门 |
| 401 的木板 | 墙纸下面的字 | 挡住视线 |
| 天台目击记录 | 缺了一块的星空 | 同一道弧线 |
| 净化分配令 | 新闻摘录 | 三角教与被分配的大楼 |
| 三角教与被分配的大楼 | 管道脉冲 | 地下供能源 |
| 地下供能源 | 检修间接线图 | 净化装置位置 |
| 净化装置位置 | 维修员交接单 | 第七天爆破计划 |
| 换水标签 | 鳞片下的人脸 | 多了一张嘴 |
| 鱼缸原来的位置 | 她记得那些抱怨 | 从鱼缸到屋里 |

当前 `city-maintenance` 是死线索，必须改成参与“第七天爆破计划”的必要证据，或明确标记为 flavor。

## 8.2 玩家引导原则

不要加任务列表。

使用四级软引导：

1. **环境**：煤气味道、锤声停止、电视雪花、广播、灯闪。
2. **人物**：邻居说“今晚别回来”；值班人说“西边检修间”；鱼说“你今天没出去”。
3. **日记**：Hugo 自己的话：
   - “第三夜。他说整栋楼。我得去看看那个开关。”
   - “邻居门口有两瓶水，一瓶没开。”
4. **线索板**：只在玩家连续失败两次后给方向，不给答案。

## 8.3 线索板反馈

必须区分：

- `NoRelation`：这两条确实没关系。
- `MissingEvidence`：有关系，但还缺一条。
- `LockedByDay`：有关系，但日期/阶段没到。
- `MissingPrerequisite`：前置剧情/物品/对话没发生。

禁止全部统一显示“这两条没有足够的联系”。

## 8.4 分支锁

- `neighbor-order` 不能只在和平招募分支获得。
- 如果玩家威胁/离开/敌对，要有替代取得方式，或明确警告。
- 第一次投锡纸必须二次确认：
  - 永久关闭鱼的人形/说话/同伴路线；
  - 对当前旅程不可逆。
