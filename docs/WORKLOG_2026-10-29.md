### 3. 独立线索板、开发者面板、主菜单与暂停

对应提交：`468cc0e`

#### 线索板

`Weekend/Assets/Scripts/Interaction/InvestigationBoardUI.cs` 重写为全屏选择式界面：

- 游戏中按 `B` 直接打开。
- `J` 日记里也可以点「线索连线」进入。
- 关闭时回到来源：
  - 从游戏打开 → 回游戏。
  - 从日记打开 → 回日记。
- 左侧是可筛选列表：
  - `全部 / 现场记录 / 推论 / 未连接`
  - 每行：类型、标题、第几天、已连接数量。
- 选中两条线索后，右侧显示：
  - 两条线索的标题和正文。
  - 「留下待证连线」。
  - 配方成立后，才出现「得出结论」。
- 待证连线不判错、可删除；结论不可删除。
- 右侧下方是「已整理的连线」：
  - `A ↔ B → 结论 / 待证`
  - 点击可回填选择。
- 键盘：
  - 方向键移动
  - 空格选择
  - Enter 建立待证 / 得出结论
  - Backspace 清空
  - Delete 擦除
  - Tab 换筛选
  - B / Esc 关闭

#### 开发者主线面板

`Weekend/Assets/Scripts/Interaction/InvestigationDevTools.cs`

入口：

1. 游戏中按 `~`
2. 输入 `1997`
3. 点击「线索开发者面板」

功能：

- `线索总览`：
  - 所有线索，包括未获得的。
  - 类型、id、标题、来源、是否已获得。
  - 每条线索参与的配方：
    - `+ 另一条 → 结论标题 (结论 id)`
  - 推论显示「由」和更高层配方。
- `全部连接`：
  - 所有 Recipe 及状态。
  - 当前 `investigationLinks`（已结论 / 待证）。
- `配方规则`：
  - `left / right / relation / id / title`
- 按钮：
  - `获得全部线索和连接`
    - 收集全部 Evidence。
    - 按配方生成全部结论和 links。
    - 处理链式依赖 `deduction-deliberate`。
    - 处理 `deduction-warning` 的 `neighborFlyersSeen` 条件。
  - `清空全部推理数据`
    - 清 links。
    - 移除证据/推论的 journal entries。
    - 移除对应 knowledgeIds。
    - 保留剧情记事。

> 所有面向玩家的叙事、对白、梦境、章节、结局、提示文案统一写在 `Assets/Resources/StoryText.json`；
> 不要重新硬编码到 MonoBehaviour；
> 线索/推理正文集中在 `StoryText.json` 的 `investigation` 段；
> `Investigation.json` 只保留结构数据；
> UI 控件文字（按钮、调试面板、状态栏）可以留在 UI 代码里。

修改 `StoryText.json` 后需要重启 Play，`StoryText` 会重新读取。
