# 2026-11-09 邻居剧情修订

用户新指示优先于 11 月 8 日规格中可反复和平对话及检修间机关收尾的部分。控制台已完成并独立推送 da22225。

审计：NeighborSlice.Go 的正式 hostile 分支只显示 early-threat；BeginDialogue 反复选择 intro/recruit；Close 无条件关闭；NeighborCombat.Win 对第二夜追逐直接恢复 Boss 血量；检修间 routing/source-core 通过两个布尔标记直接完成阶段。这些是本轮要消除的实际原因。

实施：

1. 保留现有 JSON 对话图，新增一次性提交节点和持久当前节点。开始邻居核心对话后，Esc/返回/重复互动不能撤销选择；读档继续当前节点。所有有效分支均汇入失控、摘帽、认知污染和第一人称遭遇；对话选项影响证据、信任与后续处理，不保证免战。
2. 邻居衰退由唯一 TimeManager 日期/分钟推导，取本轮已经达到的最高值；对话压力另计，不能通过退出对话或换场恢复。帽子在真实遭遇前保留。沿用首次暴露 -20 SAN。
3. 第二夜遭遇恢复有限 Boss 血量，可击退；逃生及首次捕获保护仍存在。已经击退则不再重复第二夜召回。
4. 地下设备间保留原供能源线索，改为交接档案与已运行设备的调查现场；取消两个开关直接救楼。原广告原稿不改。
5. 第七日所有已提交的对话分支进入最后遭遇。击退后取得其控制器，再以调查所得完成撤回、逼其口述解除或组织撤离；现场不再凭空出现救楼阀门。准备不足时可继续调查，不能凭一个按钮获救。
6. 保持 Save v7 的增量兼容，重置/短轮回明确清理对应新状态。历史规则仅用于已有显式隔离测试，正式验收更新为本轮明确的新契约。
